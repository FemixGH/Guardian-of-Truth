Airline-specific rules to check (from the policy):
- Any write (book_reservation, update_reservation_flights/baggages/passengers, cancel_reservation, send_certificate): the agent must have listed the exact action details and received an explicit "yes" from the user for exactly this action; otherwise hallucination.
- cancel_reservation is allowed only if: booked within the last 24 hours (compare created_at with the current time stated in the policy), OR the airline cancelled the flight, OR the cabin is business, OR the user has travel insurance and the reason is covered (health/weather). If any segment was already flown -> transfer, not cancel.
- Basic economy FLIGHTS cannot be modified, but every reservation, including basic economy, CAN change cabin (unless a flight was already flown) - saying a basic economy cabin cannot be upgraded is a false refusal; cabin must stay the same across all flights of a reservation, so a cabin change, and its price quote, must cover ALL flights of the reservation (outbound and return); the number of passengers cannot change; insurance cannot be added after booking.
- Flight change payment: a single gift card or credit card already in the user profile. Booking: at most 1 certificate, 1 credit card, 3 gift cards, all from the profile; payment amounts must match the price.
- Free checked bags depend on membership tier and cabin exactly as stated in the policy; nonfree_baggages must follow that table; do not add bags the user does not need.
- Compensation (certificate) only if the user explicitly asks AND is silver/gold, or has insurance, or flies business; never proactively.
- Prices, totals and dates must be recomputed from tool results; "upcoming" means after the current time stated in the policy.
- A request the policy forbids (cancellation that meets none of the conditions, changing origin/destination/trip type, modifying basic economy flights, adding insurance or passengers, unrequested compensation) must be DENIED by the agent. Offering or performing a transfer to a human agent for such a request is a premature escalation = hallucination, unless the user explicitly asked for a human agent (or any portion of the flight was already flown).
Airline things that are NOT hallucinations: several lookup/search calls in one turn (get_reservation_details for every reservation of the user, searches over several dates/airports); asking for user id, reservation id, cancellation reason or payment method; ordinary itinerary search steps.
